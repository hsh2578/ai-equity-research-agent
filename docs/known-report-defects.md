# 발간 리포트의 알려진 결함

v5.5 에서 죽어 있던 검증(B13 분기 누락)을 복구하자 기존 리포트에서 결함이 드러났다.
여기 기록해 두는 이유는, 고치지 않고 넘어간 것을 나중에 "몰랐다" 고 하지 않기 위해서다.

`python scripts/verify_numbers.py {종목}` 으로 언제든 재확인할 수 있다.

## 상태

| 종목 | 발간일 | 결함 | 상태 |
|---|---|---|---|
| 기아 | 2026-04-10 | 분기 라벨에 연도가 없어(`Q1~Q4`) 표가 자립하지 못함 | **수정 완료** (2026-09-08) |
| 두산 | 2026-04-20 | **분기 영업이익이 전부 틀림** + 1Q25 누락 (아래 상세) | 미해결 (실측 확보 완료) |

| OCI홀딩스 | 2026-05 | 밸류에이션 전제 "3.5 -> 7만톤 증설(2029)" 이 **DART 공시 3건 어디에도 없음** (실제 공시는 5만 6,600톤 + "증설 여부 결정 예정") | 미해결 |
| 밴드 표현 10건 | 여러 | **무효 밴드를 근거로 쓴 리포트** (아래 상세) | 미해결 |

## 전수 감사 (2026-09-09, `scripts/fleet_audit.py`)

v5.14(`source_coverage`)·v5.15(`section_rubric`)를 만들고 **작업 중인 리포트에만
돌렸다.** 43건 전수로 돌리니 **35건이 결함**이었다.

```bash
python scripts/fleet_audit.py                 # 전체
python scripts/fleet_audit.py --since 2026-09-01
```

| 구간 | 건수 | 상태 |
|---|---|---|
| **2026-09-08 이후** | **8** | **전부 0 FAIL -- 현행 기준** |
| 2026-08 | 4 | 루브릭 5~8 FAIL (한국콜마·OCI홀딩스·덕산네오룩스·씨에스윈드) |
| 2026-04~06 | 31 | 루브릭 4~10 FAIL, 출처는 1차 덤프가 없어 판정 불가 |

### 왜 소급 수정하지 않는가

**4~6월 리포트는 데이터가 5개월 지났다.** v5.4 규칙 8 이 "7일 이상 경과 시
전면 재수집"을 요구하므로, 이것들을 고치는 것은 수정이 아니라 **새로 쓰는 일**이다.
그 사이 분기 실적이 두 번 나왔고 주가도 크게 움직였다.

**대신 상태를 안다.** 이 표의 목적은 옛 리포트를 최신인 줄 알고 인용하지 않는 것이다.
그 종목을 다시 다룰 때는 고치는 게 아니라 `/research` 를 새로 돌린다.

### 결함의 성격

대부분 **v5.15 6축 루브릭의 필수 도구 누락**이다 -- DCF 또는 미사용 사유,
민감도 분석, ROE/DuPont, bottom-up 산식. 그 검증기가 없던 시점에 쓴 것이라
당시 기준으로는 통과였다. **수치가 틀렸다는 뜻이 아니다** --
`verify_numbers` FAIL 은 대부분 0~2건이다.

## 기아 -- 수정 내역

`quarterly.headers` 를 `['', 'Q1', 'Q2', 'Q3', 'Q4', '연간']` 에서
`['', '1Q25', '2Q25', '3Q25', '4Q25', '연간']` 로 바꿨다.
데이터는 원래 완전했고 연도가 `quarterly.year` 필드에만 있어 표가 자립하지 못했던 것이다.
수정 후 B1~B18 전체 통과. 원본은 git 이력에 있다 (`git show HEAD~1:scripts/analysis_기아.json`).

## 두산 -- 분기 영업이익이 전부 틀렸다

처음에는 "FnGuide 가 최근 4분기만 주니 1Q25 소급 불가" 로 판단했다. **틀린 판단이었다.**
사용자가 "DART 에서 분기 데이터 못 가지고 오나?" 라고 물어 확인해보니
DART 는 연도별 분기보고서를 그대로 제공한다.

`python scripts/dart_quarterly.py 두산 2025 --compare` 실측 (억원):

| 분기 | 리포트 | DART 실측 | 오차 |
|---|---|---|---|
| 1Q25 | **누락** | 1,985 | -- |
| 2Q25 | 약 2,500 | **3,578** | **-30.1%** |
| 3Q25 | 약 2,700 | **2,313** | +16.7% |
| 4Q25 | 약 2,500 | **2,752** | -9.2% |
| 연간 | -- | 10,627 | 검산 0.00% 일치 |

FnGuide 도 3Q25=2,312.69 / 4Q25=2,752.08 로 독립 확인된다.
누락 하나가 아니라 **있는 값도 전부 어긋나 있었다.**

## 에코프로 -- 실측은 확보했다

`python scripts/dart_quarterly.py 에코프로 2025` (억원): 1Q 매출 8,068/OP 14,
2Q 9,317/162, 3Q 9,594/1,494, 4Q 7,151/468, 연간 34,130/2,138 (검산 0.00%).

작업 중 발견: 에코프로는 손익계산서(IS) 0개 / 포괄손익계산서(CIS) 26개로 제출한다.
많은 회사가 둘을 분리하지 않는다. IS 만 보면 전 계정이 None 이 되어
"실적 없음" 으로 조용히 통과한다. `dart_quarterly.py` 가 CIS fallback 을 갖도록 고쳤다.

## 왜 리포트를 지금 고치지 않았나

실측은 확보했지만 **5개월 지난 리포트에 오늘 값만 끼워 넣으면 시점이 섞인다.**
분기 실적이 틀렸다는 것은 그 위에 쌓은 서술(사이클 판단, 일회성 해석, 밸류에이션)도
다시 봐야 한다는 뜻이다. 부분 패치가 아니라 **`/research 두산` 재실행**이 맞다.

지금 확보한 `data/{종목}/_dart_quarterly.json` 이 재실행 시 그대로 쓰인다.

## OCI홀딩스 -- 가장 심각

`bear-researcher` 가 찾았고 내가 원문으로 독립 검증했다.

- 리포트가 "7만톤" 을 25회, "2029" 를 35회 주장하며 목표주가 산식의 전제로 썼다
- DART 공시 3건(사업보고서/1분기/3분기) 전부에서 `7만톤` **0건**
- 실제 공시는 "3만 5,000톤에서 **5만 6,600톤**까지 확대할 계획이나 ... 증설 계획 실행 시점을 조율할 예정"
- 전제를 정정하면 목표가 285,000 -> 236,000원(-17.2%), 할인율까지 바로잡으면 186,000원

이건 라벨 문제가 아니라 **밸류에이션 결론이 바뀌는 사안**이라 리포트 재작성이 필요하다.

## 밸류에이션 밴드 -- 21종목 중 11종목이 통계적으로 무효였다

US 에만 있던 밴드 유효성 가드를 KR 에 이식하자(`fdr_band.py` + `verify_numbers.py` B23)
두 가지가 드러났다.

### (1) 진행 중인 당해년도가 밴드를 오염시키고 있었다

FDR 이 2026년 마지막 거래일 종가를 '연말 종가' 로 만들고,
`financial_summary` 의 2026년 **부분 실적**과 나눠 가짜 배수를 밴드에 넣고 있었다.

| 종목 | 밴드에 들어가던 가짜 PER | 정상 이력 |
|---|---|---|
| OCI홀딩스 | **34,062배** (EPS 8원) | 1.7~11.8 |
| CJ프레시웨이 | 86.4배 | 5.2~8.0 |
| 덕산네오룩스 | 54.4배 | 15~31 |
| 헥토이노베이션 | 32.8배 | 5.4~8.5 |
| 한국콜마 | 35.3배 | 11.7~14.4 |

### (2) 무효 밴드를 근거로 쓴 리포트 10건

변동계수(std/mean) > 0.6 이거나 표본이 부족해 평균·z-score 해석이 무의미한데도
본문이 "5년 평균 대비", "역사적 최저권", 시그마 등을 논거로 쓴 리포트:

**GS리테일 · OCI홀딩스 · 두산 · 삼성전자 · 씨에스윈드 · 에스엠 · 카카오 · 풍산 ·
한화에어로스페이스 · 휴림로봇**

예 -- 삼성전자: "Forward PER 5.92x는 5Y 평균 17.25x의 34% 수준, 역사적 최저권".
그 17.25배는 표준편차가 10.47(CV 0.61)이고 2023년 36.84배가 평균을 끌어올린 값이다.
"평균 대비 34%" 라는 서술이 성립하지 않는다.

**한국콜마는 통과했다.** 본문이 스스로 "5년 평균 74.39배는 2022년 순손실 구간의 왜곡
때문에 의미가 없으므로 비교 기준으로 쓰지 않는다" 고 밝혔기 때문이다.
B23 은 저자가 표현 옆에서 무효를 선언하면 단정으로 세지 않는다 --
정직한 문장을 지우도록 유도하면 안 된다.

### 지금 상태

B23 은 `_per_band.json` 이 **새 형식일 때만** 작동한다(구버전은 SKIP -- 거짓 FAIL 방지).
위 10건은 해당 종목의 `_per_band.json` 을 `fdr_band.py` 로 재생성해야 실제로 잡힌다.
`/research {종목}` 재실행 시 자동으로 재생성된다.

### KR 이식 중 발견한 함정 (US 와 다르다)

US 판은 순이익/EPS 로 주식수를 역산해 액면분할 기준 혼재를 걸러낸다.
**KR 에서는 이 방법을 쓰면 안 된다.** 연결 순이익은 비지배지분을 포함하고
EPS 는 지배주주 기준이라, 저마진 연도나 지주사에서 배수가 통째로 어긋난다
(두산 4.2~4.3배, GS리테일 4.69배, 에스엠 0.04배).
이걸로 연도를 제외하면 **분산이 큰 해가 조용히 지워져 노이즈 밴드가 유효로 뒤집힌다**
(에스엠 PER 97배 연도 소멸 -> CV 0.97 -> 0.38 "유효").
그래서 KR 은 명시 주식수가 있을 때만 판정하고, 없으면 CV 가드가 대신 잡는다.
