# 스파이크: 채굴 서브에이전트가 리포트 품질을 실제로 올리는가

**결론: 올린다. 채택한다.** 단, **작성이 아니라 채굴/반증에만** 쓴다.

- 판정 기준(사전 합의): **중대 결함 발견** -- 목표주가나 투자의견을 실제로 바꾸는 것만 카운트
- 표본: 발간 완료된 리포트 2건 (OCI홀딩스, 한국콜마)
- 방법: 같은 원문 데이터에 `bear-researcher` 를 붙이고, 발간 리포트가 놓친 것을 센다.
  이미 완성된 리포트가 반사실(counterfactual) 역할을 한다.

## 왜 이 설계인가

진짜 A/B(같은 종목에 `/research` 두 번)는 40~60분 x 2회에 $8~14 이고,
LLM 비결정성 때문에 차이가 팬아웃 때문인지 운 때문인지 구분되지 않는다.
발간 리포트를 반사실로 쓰면 비용이 1/10 이고 비교 대상이 고정된다.

## 결과

### OCI홀딩스 -- 중대 결함 1건 (밸류에이션 전제 날조)

| | |
|---|---|
| 리포트 주장 | "폴리실리콘 3.5 -> **7만톤** 증설, **2029년** 완료" -- 목표주가 산식의 전제 |
| 등장 횟수 | "7만톤" 25회 / "2029" 35회 |
| DART 공시 3건 | `7만톤` **0건** |
| 실제 공시 | "3만 5,000톤에서 **5만 6,600톤**까지 확대할 계획이나 ... 증설 계획 실행 시점을 조율할 예정" |
| 영향 | 목표가 285,000 -> 236,000원(-17.2%). 할인율까지 정정하면 186,000원 = 리포트 자체 Bear(168,000) 근처 |

부수 발견: 회사가 스스로 공시한 "말레이시아 폴리실리콘 공장 약 4개월간 가동 중단",
비중국 판가 3년 연속 하락(27.07 -> 19.97 -> 18.08 USD/kg), 리포트가 18회 인용한
2Q26 수치의 **1차 출처 부재**.

**독립 검증**: 내가 직접 grep 으로 4건 모두 확인했다.

### 한국콜마 -- 중대 결함 2건

**(1) 결론이 하루치 종가에 걸려 있었다**

리포트는 8/28 종가 161,700원(당일 +10.91% 스파이크)을 앵커로 HOLD 를 냈다.
그 스파이크는 6거래일 만에 전액 되돌려졌다.

```
8/27 145,800 -> 8/28 161,700 (+10.91%) -> 9/1 155,000 -> 9/4 145,800 -> 9/7 144,300
```

HOLD 를 떠받치던 세 수치가 전부 그 하루에 의존했다:
상승여력 +2.7% / R/R 1:0.06 / 확률가중 기대수익 -3.5%.
144,300원 기준으로 재계산하면 **+15.0% / 1:0.36 / +8.1%** 로 결론이 뒤집힌다.
결정 로그 실측 alpha 는 **-12.8%** 로, HOLD 가 아니라 SELL 이 맞았다.

**(2) 성장의 30.5%가 계열사 인수인데 리포트가 언급조차 안 했다**

1H26 화장품 부문 +24.8% 중 570.9억(콜마유엑스 403.1억 + 콜마스크 167.8억)이
신규 연결 편입분이다. 제외하면 유기적 성장은 **+17.3%**.
두 건 모두 콜마홀딩스·콜마비앤에이치라는 **계열사로부터의 이전**이다.

| 리포트 내 언급 횟수 | |
|---|---|
| 콜마유엑스 | **0회** |
| 콜마스크 | **0회** |
| 에치엔지 | **0회** |
| 매출채권 | **0회** |
| 운전자본 | **0회** |

리포트는 이 성장을 "영업 레버리지가 실제로 작동하기 시작했다" 로 해석했다.

**독립 검증**: 주가 시계열(FDR), 언급 0회, ASP 원문(`2,854`/`8.96%`), 배수 서술 모두 확인.
*(에이전트가 "FCF 0회" 라고 했으나 실제로는 `잉여현금` 이 20회 나온다 -- 이 부분은 부정확했다.
`매출채권`/`운전자본` 0회는 사실이다.)*

부수 발견: 실격 조건 **5개 중 5개** 걸림(노출도 3.07% / 가격결정력 없음 -- 2026 반기보고서
전 품목 판가 하락 / 병목 반대편 -- 회사가 "발주·납기는 매출처가 결정" 명시 /
여유 캐파 -- 그룹 화장품 가동률 56.7% / 해소일정), 목표가 배수 19배가 리포트 자신이
"정상 15배, 상단 18배" 라 쓴 것을 넘김.

**2종목 2/2 에서 목표가·투자의견을 바꾸는 결함을 찾았다.** 기준 충족.

## 왜 이게 "팬아웃" 의 증거인가

세 리포트 모두 `report-critic` 3회를 이미 통과했거나, 최소한 작성자 자신의
s14(숏 논거)와 v5.2 Self-Attack 을 거쳤다. 그런데도 이 결함들이 남아 있었다.

차이는 **컨텍스트 분리**다. `bear-researcher` 는 리포트를 어떻게 썼는지 모르고,
반대편만 파도록 역할이 고정돼 있다. 사용자의 `bottleneck-scouting` 스킬이
리포트 663편 실측으로 내린 결론과 같다:

> "반증 수집이 이 워크플로에서 가장 값이 크다. **최종 판정의 대부분을 반증이 결정했다.**"

## 채택 범위 -- 작성은 팬아웃하지 않는다

TradingAgents 의 4인 분석가 구조를 그대로 가져오지 않은 이유:

1. 논문에 **컴포넌트별 ablation 이 없다** (3종목·3개월·거래비용 0·Sharpe 8.21).
   4인 구조가 성능을 냈다는 근거가 논문 안에 없다.
2. 우리 v3 6-서브에이전트 실험은 **작성을 나눠** 비용 4~5배에 품질 개선 marginal 로 폐기됐다
   (`.claude/agents/README.md`). 입력 55%가 중복이었고 사고가 파편화됐다.
3. 저쪽 4인은 **서로 겹치지 않는 데이터 소스를 캐는 채굴자**이고 작성은 단일 에이전트가 한다.
   우리가 폐기한 것과 다른 구조다.

그래서 **채굴/반증만 분리하고 작성은 단일 유지**가 맞다.

## 남은 검증

- 표본 2건은 결론을 내기에 적지만, 2/2 에서 목표가를 바꾸는 결함이 나왔고
  전부 1차 출처로 독립 검증됐다. 더 큰 표본은 리포트를 새로 낼 때마다 자연히 쌓인다.
- **`bear-researcher` 결과를 액면 그대로 믿지 않는다.** 한국콜마에서 "FCF 0회" 가
  부정확했다. 인용은 `file:line` 이 붙어 검증 가능하므로, 중대 결함은 반드시 직접 확인한다.
- 에이전트가 스스로 "내가 찾지 못한 것" 을 보고하게 한 것이 유용했다.
  한국콜마에서는 상대강도(RS) 판정이 **강세 쪽 근거**임을 자진 보고했다.
